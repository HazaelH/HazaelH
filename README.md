## 🚀 Sobre mí

Soy estudiante de **Ingeniería en Tecnologías de la Información** enfocado en el desarrollo de software robusto, la integración de hardware con plataformas web e interfaces interactivas de alto rendimiento. Mi trabajo abarca desde la creación de ecosistemas IoT con microcontroladores y lectores ópticos hasta backends asíncronos, simulaciones 3D en WebGL y despliegues con contenedores.

- ⚡ **Backend & APIs:** FastAPI (Python), Laravel (PHP), WebSockets, REST, SQLAlchemy Async, Alembic.
- 💻 **Frontend & Web:** Vue 3, Vite, Tailwind CSS, JavaScript (ESM), Blade.
- 🎮 **Gráficos 3D & WebGL:** Three.js, WebGL 2, Blender (Python automation, shaders, GLTF/GLB).
- 🔌 **IoT & Hardware:** ESP32, PlatformIO, lectores ópticos GM60, displays ST7789, sensores (MQ-2, MQ-135, DHT11), MQTT, C++.
- 🐳 **Infraestructura & DevOps:** Docker, Docker Compose, Linux, Nginx, PostgreSQL, MySQL.

🎯 **Objetivo:** Oportunidades Junior o residencias/prácticas profesionales donde pueda resolver retos técnicos complejos, aportar valor en arquitectura de software y continuar creciendo profesionalmente.
